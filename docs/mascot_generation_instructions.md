# 🎨 .NET Mascot Generation Instructions

The `mascot.png` image in this directory was generated using an AI image generation tool to match the cohesive high-tech aesthetic of our other SDKs.

## 💡 Idea and Concept
The mascot is inspired by the official **.NET bot**, the iconic robot mascot of the .NET ecosystem. We reimagined the .NET bot as a **sleek, cybernetic entity** featuring glowing electric cyan and deep azure circuit board patterns with illuminated visor eyes on a dark high-tech background. This design brings the .NET bot into the unified, futuristic FinTech aesthetic established by the Rust, Node.js, PHP, C++, and Golang SDK mascots, complete with the polished 'XYO Financial' plate.

## 📋 Recreation Details
* **Reference Images Used:** 
  * `official_bot.png` (Official .NET Bot frontal illustration from [dotnet/brand](https://raw.githubusercontent.com/dotnet/brand/refs/heads/main/spot-illustrations/bot_frontal.png))
  * `picks/dotnet_mascot_sleek_neon_v2.jpg` (Initial sleek neon bot concept)
  * `../../rust/docs/rust_mascot_sleek_neon.jpg`
  * `../../golang/docs/mascot.png`
* **Prompt Used:** "A futuristic sleek neon illustration of the .NET bot robot mascot. Crisp electric cyan and deep azure glowing neon lines, intricate cybernetic circuit motherboard patterns on spherical body, glowing digital visor eyes, subtle neon circular frame, dark high-tech background with glowing data traces, brushed metal plate at bottom reading 'XYO Financial'. Closely matching the lighting, pose, and aesthetic of reference image 1."
